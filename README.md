# Practice

Go と Python を自分で書けるようになるための学習用リポジトリです。

## 学習ログを始める

`go/README.md` と `python/README.md` は日々の学習ログです。個人の進捗を含むため Git では管理しません。clone 後に、次のコマンドでテンプレートから作成してください。

```bash
cp go/README.template.md go/README.md
cp python/README.template.md python/README.md
```

以後は `README.md` を更新します。`README.template.md` は各言語の初期フォーマットとして変更せずに残し、学習ログ作成時の唯一のテンプレートとして使います。

テンプレート内の `{YYYY-MM-DD}` は、Codex がログを初めて作成・更新するときにその日のローカル日付へ置き換えます。既存の学習ログが古い形式の場合も、学習履歴や理解状況を残したまま最新形式へ移行します。

学習ログに加えて `go/exercises/` と `python/exercises/` の問題・回答コードもローカル学習データとして扱い、Git では管理しません。Git 管理するのはテンプレート、Skill、運用ルールなどの共通部分です。

## 学習の進め方

`go/README.md` と `python/README.md` は、それぞれの言語専用の学習記録です。学んだ文法や標準ライブラリ、自力で作れたプログラム、つまずいた点、次に確認したいことを残します。

Codex は次の問題を作る前にこの記録を読みます。実際に書いて動かせた内容を理解済みとして扱い、あいまいな点や未着手の分野から、10〜30 分で取り組める小さな問題を選びます。問題を解いた後は、コードと実行結果を渡してログを更新します。

このサイクルを繰り返し、基本文法と `import` から始めて、制御構文・関数、エラー/例外処理、データ構造、ファイル・テスト、アルゴリズム、HTTP、データベース、認証・セキュリティを経て、小さな Web アプリケーションを自力で作れる状態を目指します。

原則として `0/4` または `1/4` の分野を継続して練習し、`2/4` に到達したら次の分野を導入できます。`3/4` と `4/4` は、複数分野を組み合わせたり理由やトレードオフを説明したりできる段階として、進級の必須条件にはしません。

## 問題を作る

Codex に `問題作って` と送ると、Go と Python の学習ログを読み、それぞれの到達度に合った問題ファイルを作成します。問題文はソースファイル先頭のコメントに書かれます。実装して実行できたら、コードと実行結果を送ってください。学習ログを更新してから次の問題へ進みます。

問題ファイルは次の規則で作成します。

```text
go/exercises/001-topic-name/main.go
python/exercises/001-topic-name/main.py
```

各言語ごとに3桁連番を使い、既存の最大番号の次を採番します。`topic-name` は内容が分かる短い kebab-case にします。既存の回答ファイルは上書きしません。
