# Practice

Go と Python を自分で書けるようになるための学習用リポジトリです。

## 学習ログを始める

`go/README.md` と `python/README.md` は日々の学習ログです。個人の進捗を含むため Git では管理しません。clone 後に、次のコマンドでテンプレートから作成してください。

```bash
cp go/README.template.md go/README.md
cp python/README.template.md python/README.md
```

以後は `README.md` を更新します。`README.template.md` は初期フォーマットとして変更せずに残します。

## 学習の進め方

`go/README.md` と `python/README.md` は、それぞれの言語専用の学習記録です。学んだ文法や標準ライブラリ、自力で作れたプログラム、つまずいた点、次に確認したいことを残します。

Codex は次の問題を作る前にこの記録を読みます。実際に書いて動かせた内容を理解済みとして扱い、あいまいな点や未着手の分野から、10〜30 分で取り組める小さな問題を選びます。問題を解いた後は、コードと実行結果を渡してログを更新します。

このサイクルを繰り返し、基本文法と `import` から始めて、関数・データ構造・アルゴリズム・HTTP/データベースを経て、小さな Web アプリケーションを自力で作れる状態を目指します。

## 問題を作る

Codex に `問題作って` と送ると、Go と Python の学習ログを読み、それぞれの到達度に合った問題ファイルを作成します。問題文はソースファイル先頭のコメントに書かれます。実装して実行できたら、コードと実行結果を送ってください。学習ログを更新してから次の問題へ進みます。
